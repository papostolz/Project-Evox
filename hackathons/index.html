e-poptis

A cloud-native Human-in-the-Loop Gateway — the unified human escalation protocol for AI agents.

The Basics
Duration 24 Hours
Dates March 27–28, 2026
Format In-person
Venue OTEACADEMY
The Problem

Every AI agent implements its own isolated escalation method — there's no unified HITL layer. Communication is strictly channel-dependent (Teams-only or email-only), making it impossible to reach the right person at the right time. No standard exists for governance, audit trails, or SLA enforcement at risk-sensitive decision points.

The Solution

e-poptis is a centralized HITL Gateway: agents submit human-input requests specifying only role, urgency, and context. The gateway routes to the right person by role, delivers via the company's preferred channel (Microsoft Teams, SMS, WhatsApp), and maintains a full audit trail while the agent waits for the approval to continue its flow.

Azure OpenAI Azure Functions Azure API Management Azure Service Bus Microsoft Teams Bot Azure Communication Services Microsoft Entra ID Cosmos DB Azure Monitor

Aria

An AI-powered customer support agent for airlines — resolves flight disruptions end-to-end, from GDPR-compliant intent detection to automatic rebooking, refunds, and meal vouchers.

The Basics
Duration 72 Hours
Dates March 6–8, 2026
Format In-person
Sponsor Netcompany (Gold)
The Problem

218,000 delayed EU flights per year cost airlines €6.5 billion annually in compensation (EU261). Affected passengers spend 30–60+ minutes queuing at help desks or calling call centers to rebook or claim refunds — with a satisfaction score of just 3.13/10 after a disruption.

The Solution

Aria — a multi-agent AI pipeline where a Customer Support Agent receives the passenger request, Presidio masks PII for GDPR compliance, an LLM Agent performs intent detection and sentiment analysis against EU261 rules and airline policies, and an Action Agent executes the resolution: rebooking, refund, accommodation, or digital meal vouchers — all in under 90 seconds.

Tech Stack
Python LLM Agent Presidio (GDPR/PII) Multi-agent Architecture Aviation APIs EU261 Compliance Rules React.js
